> 对应代码：`frontend/` ｜ 技术栈：Vue 3.5 + Vite 6 + TypeScript 5 + Pinia + Element Plus + ECharts 5 + frappe-gantt

## 2. 路由与页面

| 路由 | 视图 | 说明 |
|---|---|---|
| `/login` | LoginView | 公开页；已登录访问自动跳 `/projects` |
| `/dashboard` | DashboardView | 全局进度仪表盘（P1-1） |
| `/projects` | ProjectListView | 项目卡片网格（状态筛选 + 卡片菜单） |
| `/projects/:id` | ProjectDetailView | 概览页 |
| `/projects/:id/tasks` | TaskBoardView | 任务看板（筛选/排序/批量/依赖编辑，P1-2/P1-3） |
| `/projects/:id/gantt` | GanttView | 甘特图 |
| `/projects/:id/logs` | DevLogView | 开发记录（创建/编辑/分页/汇报导出，P1-4） |
| `/keys` | ApiKeysView | API Key 管理 |
| `*` | NotFoundView | 404 页面（P1-5） |

**登录守卫**（`router.beforeEach`）：非公开路由无 token → `/login?redirect=...`；登录成功回跳。

**document.title**（`router.afterEach`）：按路由名映射中文标题，如「任务看板 · HPF Work Manager」。

**全局搜索**（P1-5）：AppLayout 顶栏集成 `GlobalSearch` 组件（防抖 300ms、≥2 字符触发、AbortController 取消重复请求），搜索按钮或 `⌘K`/`Ctrl+K` 快捷键聚焦；结果覆盖项目/任务/里程碑，点击跳转对应页面。

## 3. 状态管理（Pinia）

`stores/auth.ts`：`token` / `user`，`login` / `register` / `logout`；持久化到 `localStorage`（`hpf_token` / `hpf_user`）。

`stores/theme.ts`：`mode`（system/light/dark）、`scheme`（light/dark，system 按 `prefers-color-scheme` 实时解析）、`setMode` / `toggle`；持久化 `hpf_theme`，并同步 `html[data-theme]`。

> 项目/任务数据由视图内直接调用 API 管理（个人/小团队规模，无跨页共享状态需求）；仅 auth 与 theme 走全局 store。

## 4. API 层（axios 封装）

`api/http.ts`：

- **请求拦截**：自动附加 `Authorization: Bearer <token>`
- **响应拦截**：直接返回 `res.data`；`401` 清凭证并跳登录；其余统一 `ElMessage.error`
- `baseURL = VITE_API_BASE || '/api'`：dev 走 vite proxy，prod 走 nginx 同源反代

`api/index.ts` 按模块导出 8 个 API 对象（auth / project / milestone / task / stats / key / devLog / devSession），全部带 TS 泛型（`http.get<T, T>`）。

## 5. 设计系统落地（Apple × Material Design 3）

> 视觉规范源：根目录 `DESIGN.md`（Apple × MD3）。**每次 UI 改动前重读 DESIGN.md 并引用 `--md-*` token。**

### 5.1 Token 分层（`design/tokens.css`）

所有 token 有浅色（`:root`）与深色（`[data-theme='dark']`）两套值，主题切换即时生效。核心角色：

| 类别 | 关键变量 | 说明 |
|---|---|---|
| 主色 | `--md-primary` | 浅色 `#0066cc` / 深色 `#4ea0ff`，唯一行动色 |
| 表面 | `--md-surface` 与 `--md-surface-container-{lowest..highest}` | 色阶提升表达层级 |
| 文字 | `--md-on-surface` / `--md-on-surface-variant` | 主/次文字 |
| 语义 | `--md-success` / `--md-warning` / `--md-error` | 状态色 |
| 状态映射 | `--md-status-todo/inprogress/done/overdue` | 业务状态 → 语义色 |
| 形状 | `--md-radius-{xs,sm,md,lg,xl,pill}` | 4/8/12/16/28/9999px |
| 间距 | `--md-space-*` | 4px 基准 |
| 动效 | `--md-duration-*` / `--md-ease-*` | 200/300ms 标准缓动 |

**规则**：组件一律引用变量，**禁止内联 hex**；除主色外不引入其他品牌色；卡片无投影，深度靠 surface-container 色阶 + hairline。

### 5.2 Element Plus 主题覆盖（`element-plus.css`）

将 Element Plus 变量映射到 MD3 角色：`--el-color-primary: var(--md-primary)`，语义色映射 success/warning/error，圆角映射 MD3 阶梯，组件高度 40px（紧凑密度）。按钮 pill、输入框 outlined（聚焦 2px 主色）、弹窗 MD3 表面、表格 hover 行、标签状态容器色。

### 5.3 语义映射（进度/状态高亮）

| 业务状态 | 颜色 token | 出现位置 |
|---|---|---|
| 任务 done | `--md-success` | 看板进度条、里程碑 tag |
| 任务进行中 | `--md-primary` | 看板进度条、状态点 |
| 任务待办 | `--md-on-surface-variant` | 状态点 |
| **任务延期** | `--md-error` | 看板卡片红边/逾期标签、概览延期列表、甘特条形 |

### 5.4 页面模式复用

| DESIGN.md 组件模式 | 本应用落地 |
|---|---|
| top-app-bar | 顶栏毛玻璃吸顶（surface 82% + blur(20px) + hairline 底边） |
| card | `md-card`（surface-container-low + lg 圆角 + 1px outline-variant） |
| button primary/tonal | 主按钮 pill 蓝底白字、次级 tonal（primary-container） |
| chip/tag | 筛选 chips、状态 tag（xs 圆角容器色） |
| linear progress | 进度条 pill 轨道 |
| dialog | 弹窗 xl 圆角 + shadow-2 |

### 5.5 甘特图定制（`gantt.css`）

- 条形纯色 `--md-primary`（覆盖 frappe-gantt 默认渐变）
- 延期任务：渲染后按 `data-id` 匹配 `overdue` 集合，给 `.bar-wrapper` 加标记 → 条形标红
- 今日线高亮；日期轴/任务名列文字使用主题高对比色（浅/深主题一致可读）
- popup 圆角白卡片无阴影

## 6. 构建与开发

```bash
npm install            # 安装依赖（含 sass-embedded）
npm run dev            # vite dev server :8080，/api 代理到 :8000
npm run build          # vue-tsc 类型检查 + vite build → dist/
npm run preview        # 预览产物
```

**chunk 拆分**（`vite.config.ts` `manualChunks`）：`echarts` / `element-plus` / `vendor`(vue、router、pinia、axios) 独立分包，业务代码按路由懒加载。

## 7. 前端注意点

- `frappe-gantt` 无 Vue 官方封装：`onMounted` 初始化、`watch` 数据 `chart.refresh()`、`onUnmounted` 销毁
- 拖拽改状态：原生 HTML5 drag 事件，目标列 drop 时调 `taskApi.update`
- 日期统一字符串 `YYYY-MM-DD`，直接与后端 `Date` 字段对接
- ECharts 图表颜色须通过 `useThemeColors` 读取 CSS 变量并在主题切换时重绘（禁硬编码色值）
- SSE 订阅统一走 `useProjectEvents`（自动断线重连、组件卸载关闭）
