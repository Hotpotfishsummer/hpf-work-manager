# 04 · 前端指南

> 对应代码：`frontend/` ｜ 技术栈：Vue 3.5 + Vite 6 + TypeScript 5 + Pinia + Element Plus

## 1. 目录结构

```
frontend/
├── Dockerfile              # 多阶段：node:22-alpine 构建 → nginx:alpine 运行
├── nginx.conf              # 静态资源 + /api 反向代理
├── vite.config.ts          # @ 别名、dev proxy、manualChunks 分包
└── src/
    ├── main.ts             # 入口：Pinia + Router + Element Plus + 样式
    ├── App.vue             # 根组件（仅 router-view）
    ├── router/index.ts     # 路由 + 登录守卫
    ├── design/             # 设计系统落地（BMW 风格）
    │   ├── tokens.css      # ★ 全部设计 token（CSS 变量，禁止内联 hex）
    │   ├── element-plus.css# Element Plus 主题覆盖（直角/蓝主色/48px）
    │   └── global.css      # 全局基础样式 + 通用类
    ├── api/
    │   ├── http.ts         # axios 实例 + JWT 注入 + 401 跳转 + 统一报错
    │   └── index.ts        # authApi / projectApi / milestoneApi / taskApi / statsApi
    ├── stores/auth.ts      # Pinia：token/user 持久化（localStorage）
    ├── types/
    │   ├── index.ts        # 与后端 schema 对齐的 TS 接口
    │   └── frappe-gantt.d.ts # frappe-gantt 类型声明（无官方类型）

    │   ├── AppLayout.vue   # 顶栏导航布局（brand + 菜单 + 用户）
    │   ├── GanttChart.vue  # frappe-gantt 封装（BMW 样式定制）
    │   ├── gantt-bmw.css   # 甘特图 BMW 定制（蓝条/延期红/今日线）
    │   └── BurndownChart.vue # ECharts 燃尽图（期望线+实际线）
    └── views/
        ├── LoginView.vue          # 登录/注册
        ├── ProjectListView.vue    # 项目卡片网格
        ├── ProjectDetailView.vue  # 概览：hero+统计+燃尽图+延期+里程碑
        ├── TaskBoardView.vue      # 任务看板：三列分组 + 拖拽改状态
        └── GanttView.vue          # 甘特图页
```

## 2. 路由与页面

| 路由 | 视图 | 说明 |
|---|---|---|
| `/login` | LoginView | 公开页；已登录访问自动跳 `/projects` |
| `/projects` | ProjectListView | 项目 4-up 卡片网格 |
| `/projects/:id` | ProjectDetailView | 概览页 |
| `/projects/:id/tasks` | TaskBoardView | 任务看板 |
| `/projects/:id/gantt` | GanttView | 甘特图 |
| `*` | — | 重定向 `/projects` |

**登录守卫**（`router.beforeEach`）：非公开路由无 token → `/login?redirect=...`；登录成功回跳。

## 3. 状态管理（Pinia）

`stores/auth.ts`：`token` / `user`，`login` / `register` / `logout`。
- token 与用户信息持久化到 `localStorage`（key：`hpf_token` / `hpf_user`）
- `username` 为 computed，供顶栏展示

> 当前仅 auth store；项目/任务数据由视图内直接调用 API 管理（个人/小团队规模，无跨页共享状态需求）。

## 4. API 层（axios 封装）

`api/http.ts`：
- **请求拦截**：自动附加 `Authorization: Bearer <token>`
- **响应拦截**：直接返回 `res.data`；`401` 清凭证并跳登录；其余统一 `ElMessage.error`
- `baseURL = VITE_API_BASE || '/api'`：dev 走 vite proxy，prod 走 nginx 同源反代

`api/index.ts` 按模块导出 5 个 API 对象，全部带 TS 泛型（`http.get<T, T>`）。

## 5. 设计系统落地（BMW 企业风格）

> 视觉规范源：根目录 `DESIGN.md`（awesome-design-md / bmw）。**每次 UI 改动前重读 DESIGN.md 并引用原文 token。**

### 5.1 Token 分层（`design/tokens.css`）

| 类别 | 关键变量 | 用途 |
|---|---|---|
| 颜色 | `--bmw-primary: #1c69d4` | 唯一主行动色 |
| | `--bmw-surface-dark: #1a2129` | 深海军蓝 hero（仅此一处深色块） |
| | `--bmw-hairline: #e6e6e6` | 1px 分隔线/描边 |
| | `--bmw-success/warning/error` | `#22c55e` / `#f59e0b` / `#dc2626` |
| 字体 | `--bmw-font: 'Inter', ...` | 700 展示 / 300 正文（无 500） |
| 圆角 | `--bmw-radius-none: 0px` | 一切矩形；`full` 仅圆形图标 |
| 间距 | `--bmw-space-*`（4→80px） | 8px 基准 |
| 控件 | `--bmw-control-height: 48px` | 按钮/输入框统一高度 |

**规则**：组件一律引用变量，**禁止内联 hex**；除 BMW Blue 外不得引入其他品牌色；**无 drop shadow**，深度靠色块对比 + hairline。

### 5.2 Element Plus 主题覆盖（`element-plus.css`）

- `--el-color-primary: #1c69d4`、`--el-border-radius-base: 0px`（全局直角）
- 主按钮 hover → `#0653b6`；禁用 → `#d6d6d6`
- 输入框聚焦描边加粗为 ink `#262626`

### 5.3 语义映射（进度/状态高亮）

| 业务状态 | 颜色 token | 出现位置 |
|---|---|---|
| 任务 done | `--bmw-success` | 看板进度条、里程碑 tag |
| 任务进行中 | `--bmw-primary` | 看板进度条、col-dot |
| 任务待办 | `--bmw-muted` | col-dot |
| **任务延期** | `--bmw-error`（红 + 700） | 看板卡片红边/逾期标签、概览延期列表、甘特条形 |

### 5.4 页面模式复用

| DESIGN.md 组件模式 | 本应用落地 |
|---|---|
| `hero-band-dark` | 项目详情页顶部深蓝横幅（项目名 + 进度环） |
| `model-card` | 项目卡片（surface-card 底板 + 名称 + "查看项目 ›"） |
| `filter-chip` | 看板筛选 chips（激活态墨底白字） |
| `category-tab` | 概览/任务/甘特图子导航（UPPERCASE + 2px 下划线） |
| `spec-cell` | 统计格（数值 24/700 + 标签 UPPERCASE） |
| `button-primary` | 全部主按钮（蓝底白字直角 48px） |

### 5.5 甘特图定制（`gantt-bmw.css`）

- 条形纯色 `--bmw-primary`（覆盖 frappe-gantt 默认渐变）
- 延期任务：渲染后按 `data-id` 匹配 `overdue` 集合，给 `.bar-wrapper` 加 `data-overdue="true"` → 条形标红
- 今日线 `rgba(28,105,212,0.08)` 高亮；popup 直角白卡片无阴影

## 6. 构建与开发

```bash
npm install            # 安装依赖（含 sass-embedded）
npm run dev            # vite dev server :8080，/api 代理到 :8000
npm run build          # vue-tsc 类型检查 + vite build → dist/
npm run preview        # 预览产物
```

**chunk 拆分**（`vite.config.ts` `manualChunks`）：`echarts` / `element-plus` / `vendor`(vue、router、pinia、axios) 独立分包，业务代码按路由懒加载。

## 7. 前端注意点

- `frappe-gantt` 无 Vue 官方封装：`onMounted` 初始化、`watch` 数据 `chart.refresh()`、`onUnmounted` 销毁
- 拖拽改状态：原生 HTML5 drag 事件，目标列 drop 时调 `taskApi.update`
- 日期统一字符串 `YYYY-MM-DD`，直接与后端 `Date` 字段对接
