## 2. 路由与页面

| 路由 | 视图 | 说明 |
|---|---|---|
| `/` | CockpitView | **AI Agent Cockpit 驾驶舱**（首页）：纵向可折叠分区（执行中 / 待调度 / 已完成）+ 分类筛选 + 项目指示入口 |
| `/ideas` | IdeaLabView | **灵感工坊**：从代码库推演下一步 / 碰撞新项目点子，一键收纳为看板任务 |
| `/quota` | QuotaView | **算力雷达**：MiniMax 5h 窗口余量、重置倒计时、驱动模式判定 |
| `/projects` | ProjectListView | 项目卡片网格（状态筛选 + 卡片菜单） |
| `/projects/:id` | ProjectDetailView | 概览页（含进度趋势图） |
| `/projects/:id/tasks` | TaskBoardView | 任务看板（筛选/排序/批量/依赖编辑/评论） |
| `/projects/:id/gantt` | GanttView | 甘特图 |
| `/projects/:id/logs` | DevLogView | 开发记录（创建/编辑/分页/汇报导出） |
| `/keys` | ApiKeysView | API Key 管理 |
| `*` | NotFoundView | 404 页面 |

> 注：9 月版本的 `/login`、`/dashboard` 已在 10 月 UI 重构中移除 —— 认证改为
> 由后端 `AUTH_REQUIRED` 控制（内网免鉴权模式下前端无需登录页，默认 `admin` 身份）。

**认证守卫**：`http` 拦截器在收到 `401` 时清除本地 `hpf_token`/`hpf_user` 并跳转；
免鉴权部署下后端不会返回 401，此路径不触发。请求仅在 localStorage 存在 `hpf_token`
时才附加 `Authorization` 头（不再伪造占位 token）。

**document.title**（`router.afterEach`）：按路由名映射中文标题，如「任务看板 · HarnessPilot · AI Agent Cockpit」。

**全局搜索**：AppLayout 顶栏集成 `GlobalSearch` 组件（防抖 300ms、≥2 字符触发、AbortController 取消重复请求），搜索按钮或 `⌘K`/`Ctrl+K` 快捷键聚焦；结果覆盖项目/任务/里程碑，点击跳转对应页面。

## 3. 状态管理（Pinia）

`stores/auth.ts`：`token` / `user`，`login` / `register` / `logout`；持久化到 `localStorage`（`hpf_token` / `hpf_user`）。

`stores/theme.ts`：`mode`（system/light/dark）、`scheme`（light/dark，system 按 `prefers-color-scheme` 实时解析）、`setMode` / `toggle`；持久化 `hpf_theme`，并同步 `html[data-theme]`。

> 项目/任务数据由视图内直接调用 API 管理（个人/小团队规模，无跨页共享状态需求）；仅 auth 与 theme 走全局 store。

## 4. API 层（axios 封装）

`api/http.ts`：

- **请求拦截**：自动附加 `Authorization: Bearer <token>`
- **响应拦截**：直接返回 `res.data`；`401` 清凭证并跳登录；其余统一 `ElMessage.error`
- `baseURL = VITE_API_BASE || '/api'`：dev 走 vite proxy，prod 走 nginx 同源反代

`api/index.ts` 按模块导出 8 个 API 对象（auth / project / milestone / task / stats / key / devLog / devSession），全部带 TS 泛型（`http.get<T, T>`）。

## 5. 设计系统落地（Material Design 3）

> 视觉规范源：根目录 `DESIGN.md`（Material Design 3）。**每次 UI 改动前重读 DESIGN.md 并引用 `--md-*` token。**

### 5.1 Token 分层（`design/tokens.css`）

所有角色色由 `frontend/scripts/gen-m3-tokens.mjs` 用 `@material/material-color-utilities` 从种子色生成（改主色只改脚本里的 `SEED_MAIN` 后重跑），写入 `tokens.css` 的 `m3-generated` 标记块之间——**不要手改这两块**。标记块之后是状态层 / 高度 / 字阶 / 形状 / 间距 / 动效等非颜色令牌，以及把旧令牌名映射到新角色的别名段（旧代码不必一次性改完）。

| 类别 | 关键变量 | 说明 |
|---|---|---|
| 主色 | `--md-primary` / `--md-on-primary`、`--md-primary-container` / `-on-…` | 最重要操作 / 进行中 / 选中 |
| 次色 | `--md-secondary-container` / `--md-on-secondary-container` | 次要操作、导航选中指示器 |
| 表面 | `--md-surface`、`--md-surface-container-{low,high,highest}` 等 | 页面底 98 → 卡片 90（浅色） |
| 文字 | `--md-on-surface` / `--md-on-surface-variant` / `--md-outline` | 正文 / 次要 / 占位 |
| 语义 | `--md-{success,warning,error}` 及各自 `-container` / `-on-…` | 状态与健康度 |
| 分类 | `--md-accent-{1..6}` 及 `-container` / `-on-container` | 任务分类、数据系列 |
| 字阶 | `--md-type-{role}-{size}` 与 `-lh-…` | M3 type scale |
| 形状 | `--md-shape-{extra-small,small,medium,large,extra-large,full}` | 4 / 8 / 12 / 16 / 28 / 药丸 |
| 高度 | `--md-elevation-{0..5}` | 卡片 0，浮层 2，对话框 3 |
| 间距 | `--md-space-{1..8}` | 4px 基准 |

**规则**：组件一律引用变量，**禁止内联 hex**；分区不描边（闸门规则「分区细边框」）；卡片无投影。

### 5.2 语义类与 Element Plus 主题覆盖

`global.css` 提供可直接用的 `.md-*` 语义类：`.md-card`（填充式卡片）、`.md-section`（分区）、`.md-chip--<tone>`（状态 / 分类芯片）、`.md-chip--filter`（筛选芯片）、`.md-callout--<tone>`（提示）、`.md-btn--*`、`.md-icon-btn`、`.md-state`（悬停 / 按下状态层）。

`element-plus.css` 把 Element Plus 映射到同一套角色：实心 / tonal（`plain`）/ 描边 / 文字四级按钮，填充式输入框（底部状态线），无描边的表格、卡片与浮层，药丸指示器页签。
## 6. 构建与开发

```bash
npm install            # 安装依赖（含 sass-embedded）
npm run dev            # vite dev server :8080，/api 代理到 :8000
npm run build          # vue-tsc 类型检查 + vite build → dist/
npm run preview        # 预览产物
```

**chunk 拆分**（`vite.config.ts` `manualChunks`）：`echarts` / `element-plus` / `vendor`(vue、router、pinia、axios) 独立分包，业务代码按路由懒加载。

## 7. 前端注意点

- `frappe-gantt` 无 Vue 官方封装：`onMounted` 初始化、`watch` 数据 `chart.refresh()`、`onUnmounted` 销毁
- 拖拽改状态：原生 HTML5 drag 事件，目标列 drop 时调 `taskApi.update`
- 日期统一字符串 `YYYY-MM-DD`，直接与后端 `Date` 字段对接
- ECharts 图表颜色须通过 `useThemeColors` 读取 CSS 变量并在主题切换时重绘（禁硬编码色值）
- SSE 订阅统一走 `useProjectEvents`（自动断线重连、组件卸载关闭）
