# 01 · 连接与认证

本服务为 AI 工具提供两条接入路径，二者共享同一套业务逻辑与数据：

| 路径 | 适用场景 | 前置 |
|---|---|---|
| **MCP Server**（推荐） | 支持 MCP 的编码工具（Claude Code、Cursor 等） | 配置一个 MCP server 地址 + 一个 API Key |
| **REST API + API Key** | 脚本 / 不支持 MCP 的工具 | 用 `/api/keys/exchange` 换 JWT |

---

## 1. MCP 端点

部署后，MCP 端点与 Web 前端**同源**：

```
https://<你的域名>/mcp
```

- 走 **Streamable HTTP** 传输（MCP 官方 HTTP 传输），一次连接内可多次请求。
- nginx 已反代 `/mcp` 到后端，并关闭缓冲以支持 SSE 流式响应。
- 生产环境务必使用 HTTPS，避免 API Key 明文传输。

本地开发（后端直连）：`http://localhost:8000/mcp`。

> 端点启用 **DNS 防重绑定**保护：仅允许配置的 Host（`MCP_ALLOWED_HOSTS`，逗号分隔；
> 留空则从 `CORS_ORIGINS` 推导，并始终包含 `localhost`）。用非允许 Host 访问会被拒绝。

---

## 2. 认证

MCP 端点的所有请求都必须在 `Authorization` 头携带凭证，二选一：

1. **API Key**（推荐，长期有效、可撤销）：`Authorization: Bearer hpf_ab12cd_<64位hex>`
2. **JWT**（7 天有效期）：`Authorization: Bearer <jwt>`（登录后获得，或用 API Key 换取）

未携带或无效凭证 → `401`。

### 2.1 创建 API Key

1. 登录 Web 前端 → 「API Keys」→ 「新建 Key」。
2. 输入名称（如 `claude-code-laptop`），点击生成。
3. **立即复制保存**完整串 `hpf_ab12cd_<64位hex>` —— 仅显示一次，丢失无法找回。

> REST 等价操作：`POST /api/keys`（需 JWT），返回体含一次性明钥。
> 吊销：`DELETE /api/keys/{id}`。

### 2.2 用 API Key 换 JWT（仅脚本场景需要）

```bash
curl -X POST https://<你的域名>/api/keys/exchange \
  -H "Content-Type: application/json" \
  -d '{"key": "hpf_ab12cd_<你的API Key>"}'
# => { "access_token": "<jwt>" }
```

拿到 JWT 后即可调用既有 REST 接口（见仓库 `docs/03-API参考.md`）。

## 3. MCP 客户端配置示例

### 3.1 Claude Code

`.mcp.json`（或 `claude mcp add hpf-work-manager ...`）：

```json
{
  "mcpServers": {
    "hpf-work-manager": {
      "type": "http",
      "url": "https://<你的域名>/mcp",
      "headers": {
        "Authorization": "Bearer hpf_ab12cd_<你的API Key>"
      }
    }
  }
}
```

### 3.2 Cursor

Settings → MCP Servers → Add：

```
Type:        HTTP
URL:         https://<你的域名>/mcp
Header:      Authorization: Bearer hpf_ab12cd_<你的API Key>
```

### 3.3 其他 MCP 客户端（通用）

本质都是指定三样：

- `url` = `https://<你的域名>/mcp`
- 请求头 `Authorization: Bearer <API Key 或 JWT>`
- 传输类型 = `http` / `streamable-http`

## 4. 实时同步（SSE）

AI 工具每次写操作后，后端会向该项目的所有 SSE 订阅者广播事件，Web 前端自动刷新：

```http
GET /api/events/stream?project_id=1
Authorization: Bearer <jwt 或 API Key>
```

事件示例：

```
event: project-update
data: {"type":"updated","entity":"task","entity_id":42,"project_id":1,"ts":"2026-08-12T05:41:00+00:00"}
```

多台机器上的多个工具连接同一服务时，进度实时一致。

---

## 5. 安全注意事项

- **API Key 无过期**，可随时撤销；建议**每工具一个 key**，便于审计与回收。
- 所有写操作都是**完整 CRUD**（AI 可创建/修改/删除），请仅向可信工具发放 key。
- API Key 落库仅存 HMAC-SHA256 哈希，数据库泄露也无法反推明钥。
- MCP 端点有 DNS 防重绑定保护；生产必须走 HTTPS。
- 环境变量：
  - `MCP_ENABLED`（默认 `true`）：是否启用 MCP 端点
  - `MCP_PATH`（默认 `/mcp`）：MCP 端点路径
  - `MCP_ALLOWED_HOSTS`（默认空）：允许的 Host 白名单，空则从 `CORS_ORIGINS` 推导
